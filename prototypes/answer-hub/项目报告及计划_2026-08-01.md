# 答疑中台知识库项目报告及计划

更新时间：2026-08-01

## 1. 结论

项目主链路已经搭起来了，当前处在“真实数据验证 + 上线前验收”阶段。
如果业务要求 **2026-08-03** 必须上线，只能采用“受控上线 / 试运行上线”方案，不能按完整自动化生产上线口径执行。

现在的系统目标很明确：

```text
第二部分脱敏会话 / 自动化上传
-> Answer Hub 队列处理
-> 原子问题拆分
-> 1～N 主题聚类
-> 主题分类与是否值得沉淀判断
-> 候选价值复核
-> CZ 待审核
-> 人工终审后发布
```

系统不会自动发布知识，正式结果仍要走 CZ 人工终审。
后天上线的前提是保留这条红线不变。

## 2. 当前进展

## 9. 风险点

- 人工标注和边界样本如果收不完，会直接拖慢上线。
- 本地全量 `pytest` 出现 1 个失败标记，并且 Windows 临时目录清理/创建存在权限问题，导致结果无法作为发布绿灯。
- MiMo、CZ、Dify 的真实联调如果有密钥、网络或容器问题，时间会往后顺延。
- 自动审核默认必须关闭，不能为了赶时间提前放开。
- 如果后天强行全量上线，最容易出问题的是品类边界、联调密钥和临时目录权限。
