- **主标题讲硬盘**（加装硬盘是否按第三方配件处理）
- **同义问法与标准项讲内存**（内存品牌属性待确认）

1. 同事问「内存品牌」，这句同义问法**能命中**它，但返回的正文是**硬盘**的处理口径 → 答非所问；
2. 同事问「加装硬盘算不算第三方」，主标题**能命中**它，但同义问法只有内存那一句 → 追问内存时又被拉过来。

### 建议

- 若正文其实是「内存品牌属性待确认」：**修正主标题**。
