## 合入审查补充修复

对适用品牌、机型、类目、场景、标准关联和副标题的修改也会增加草稿版本并使旧初标失效。
人工价值复核通过服务端 `human_review_draft_version` 绑定当前草稿；修改或采用模型修订稿后，
旧人工结论不能自动确认新草稿，也不能作为新草稿的评测真值。

人工价值和可用性复核可以直接形成评测真值，不再要求人工额外填写由模型负责的
草稿处理字段。缺少当前模型结果、模型初标失效或人工确认版本不一致时，不冻结有效真值。

Prompt 修订输入仅允许明确属于 train/validation 的样本；test 的逐项答案、输出、
自由文本归因和验收统计不传入修订模型。原有测试退化的人审门禁和审计记录保留。
已经参与过历史选版或归因的旧测试集只适合作诊断性回归；报告独立最终测试结果前，
仍需准备未参与迭代的新 holdout。

迁移 `20261018_01_merge_review_heads` 汇合已有盲标迁移和本次候选评测迁移。
该汇合迁移不执行数据修改。迁移历史检查支持 Alembic 的多父节点，并检查父节点存在。
