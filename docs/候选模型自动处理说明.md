# 候选模型自动处理

本次基于主分支 `e8821228e34310a2bd802662cedc67e6fdcbc51d`，包含曼哈顿品类白名单及旧缓存修复，同时修复候选回收业务分类和批量请求执行方式。

## 回收业务分类

十二品类为手机、平板电脑、智能手表、耳机/耳麦、笔记本、游戏机、游戏卡带、单电/微单机身、单反机身、相机镜头、手写笔、学习机。

有明确产品证据且属于十二品类之外的候选归为聚合回收，覆盖旧的自营默认值。来源结构化品类优先，旧值只作审计。品类占位值不遮蔽后续明确产品；类别对象中的名称、业务路径、常用品类别名和复合产品字符串均可识别。内部类别 ID 不被当成产品名称。十二品类已有明确的聚合业务记录继续保留。

Answer Hub 在预处理及业务层级映射时应用该规则；主站在候选接收、详情读取、模型处理和送审时应用该规则。不凭标题中的设备词猜测产品，也不批量改写已进入知识库管理的历史知识。

## 页面操作

在“候选价值复核”勾选“自动模型标注并送审”，服务端会扫描已有及后续新增的未人工复核候选，每批最多 100 条、逐条处理。处理状态包含待人工确认、待模型初标、退回转写和已可送审；待补证据、不沉淀、已人工复核和已送审的候选不被自动扫描。

手动选择 20、50、100 条点击“批量模型标注并送审”同样创建持久化后台任务。创建请求返回 HTTP 202，不等待模型完成。页面显示进度、修订和送审计数、逐条结果、失败重试和历史任务分页，关闭页面后继续处理。

流程复用候选创建时间对应的已批准 Prompt，允许一次模型修订，再次初标，通过原有置信度和风险门禁后执行查重，最终只进入知识库待审核。权限失效会停止任务。自动开关默认关闭；关闭后当前条完成，后续自动条目停止，手动任务不受影响。

同一草稿版本的自动尝试只执行一次。失败后可以手动重试；修改草稿生成新版本后可再次自动处理。单条失败保留结果并继续下一条。已记录结果不会重复执行。进程中断的当前条保留已保存内容、标记中断供人工检查重试，后续候选继续；不会因恢复重复采用修订。

## 数据库升级

新增迁移 `20261027_01_candidate_tasks`，父节点为当前迁移头 `20261013_01_hf_persist`。新增任务表、自动设置表和默认关闭的设置记录，不改写历史候选。

在已确认的部署环境先备份数据库，随后按项目现有发布流程执行迁移：

```powershell
Set-Location backend
python -m alembic upgrade head
```

后端启动时运行任务 worker。PostgreSQL 会话级 advisory lock 保证同一时间只有一个模型任务执行者；租约用于进程退出后的恢复。任务表记录当前执行候选，避免恢复时再次修改已经提交的草稿。

上线需要同时交付后端、前端和 Answer Hub 的分类改动。本说明不代表已创建 PR、已部署或已开启生产自动处理。

## 验证边界

自动化测试使用隔离 SQLite 数据库和模拟模型响应，覆盖 20/50/100 条创建、50/100 条逐条执行、模型风险门禁、失败继续、去重、权限、自动关闭、中断保护、草稿版本和历史分页。浏览器验收使用本地模拟接口，覆盖自动开关、100 条入队、进度、失败明细、非 JSON 网关错误和页面运行错误。
