# Excel 批量导入知识

知识工作台支持通过同一套后台任务导入普通知识或机型配置信息。
模板下载和文件上传均使用 `import_type` 区分：

- `knowledge`：普通知识，缺省值。
- `model_configuration`：机型配置信息。

## 普通知识

1. 在“知识工作台”点击“下载导入模板”。
2. 在“知识导入”工作表填写数据。
3. 从“分类字典”工作表复制分类 ID，填写到“知识分类”列。
4. 点击“Excel 批量导入”并选择填写后的文件。
5. 查看成功数量和逐行失败原因；成功知识会进入待审核状态。

模板表头会直接标注“必填”或“选填”；前三列为必填，其余列均为选填。

## 字段

| 字段 | 必填 | 说明 |
|---|---:|---|
| 标题 | 是 | 最多 256 个字符 |
| 知识分类 | 是 | 推荐填写分类 ID，也支持唯一分类名称或完整分类路径 |
| 正文 | 是 | 纯文本正文，最多 100000 个字符 |
| 副标题 | 否 | 多项使用中文分号 `；` 分隔 |
| 场景标签 | 否 | 多项使用中文分号 `；` 分隔 |
| 适用类目 | 否 | 多项使用中文分号 `；` 分隔 |
| 适用品牌 | 否 | 多项使用中文分号 `；` 分隔 |
| 适用机型 | 否 | 多项使用中文分号 `；` 分隔 |

## 导入规则

- 单个文件最多 500 条、最大 5MB，仅支持 `.xlsx`。
- 每行独立校验和入库，单行失败不会回滚已经成功的其他行。
- 成功知识的来源标记为 `excel`，状态为待审核。
- 分类不存在、格式错误、疑似重复或完全重复的行不会入库，并返回对应错误原因。
- 导入过程复用人工新建知识的查重、向量生成和检索索引逻辑。

## 机型配置信息

下载模板时选择 `import_type=model_configuration`。专用模板工作表名为
“机型配置信息”，上传时也兼容原始工作表名“个性化配置信息”。

专用模板字段：

| 字段 | 必填 | 说明 |
|---|---:|---|
| 来源知识ID | 是 | 上游稳定ID，用于重复上传时幂等更新；不是中台 `A-xxxxx` ID |
| 标题 | 是 | 最多 256 个字符 |
| 品类ID、品类 | 是 | 原始飞书表同时缺少两列时默认使用 `119 / 平板电脑` |
| 品牌ID、品牌 | 是 | 精确匹配的品牌范围 |
| 型号ID、型号 | 是 | 精确匹配的机型范围 |
| 是否有卡槽等配置列 | 否 | 原样保留在来源字段中 |
| 综合内容 | 是 | 展示正文，最多 100000 个字符 |

机型配置导入规则：

- 单个文件最多 5000 条、最大 5MB，仅支持 `.xlsx`。
- 整本工作簿先完成字段、重复来源ID和重复机型键校验，再开始写库。
- 所有记录在一个数据库事务内同步；任一数据或数据库冲突都会整批回滚。
- 相同数据重复上传不会新增知识；字段变化会保留中台知识ID并原地更新。
- 成功记录直接发布为 `model_configuration`，固定使用
  `self_operated / cat-extra-knowledge / integration`。
- 不执行语义查重，不生成查重或检索向量，不进入普通审核。
- 后台任务会分别统计新增、更新和无变化数量，逐行结果包含操作类型和中台知识ID。
