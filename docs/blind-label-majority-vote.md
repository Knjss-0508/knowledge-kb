# 召回标注自动多数表决

- 针对盲标工单中冻结的同一个问题，按独立标注员计票。投满工单预设人数后才出结论（新工单 5 人，历史工单保留原人数）。有任一个可参考候选算该问题 1 张可参考票；显式标记全部候选不可参考算 1 张不可参考票。超过已提交人数一半即为该问题的最终结论，例如 4:1 或 3:2 均自动结案。投满但无多数时显示「未形成多数」，不强行判正负。
- 工单可参考不代表某个候选正确。候选分别统计显式票，只有同一候选获得过半的同向票才得出候选结论。选了别的候选不视为给本候选投反对票。若可参考票分散、各候选均未过半，工单可以显示「可参考」，但不指定赢家。
- 总览的可参考／不可参考筛选按工单最终结论；详情同时展示问题和各候选的显式票数。历史仲裁仍可查看，旧写入接口返回 `410 Gone`。管理员回收派发权限保持不变。没有数据库迁移或数据回填，旧的未仲裁工单按新规则读时计算。
